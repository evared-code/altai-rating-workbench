Rating rule G1–G5

  1. G1Applicability is decided in element 1 of the registered plan. A criterion registered as not applicable gets no rating.
  2. G2List the expected elements: each measure, and each subgroup the acceptance criterion names.
  3. G3Compare each element with the registered acceptance criterion, using only evidence about this component as the app uses it (its version, setting and population). Mark it shown met, shown not met, or missing.
  4. G4Any element shown not met → Not met. None shown → Cannot judge. All shown met → Met. Otherwise → Partly met.
  5. G5Record claim, evidence and argument. Not met becomes Fix before release. Missing evidence becomes Ask producer (class N, counts in ΔR) or an Own task on the app side (classes O and C).
